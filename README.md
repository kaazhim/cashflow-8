# Cashflow 8

A browser-based, eight-week cashflow planner built with React and Vite. Start with sample bakery figures, add or move payments, and see each week's projected ending balance. Changes are saved in this browser using local storage.

## Run locally

```sh
npm install
npm run dev
```

Open the URL shown by Vite (usually `http://localhost:5173/`).

## Build

```sh
npm run build
npm run preview
```

The production files are generated in `dist/`. No account, server, or environment variables are required.
